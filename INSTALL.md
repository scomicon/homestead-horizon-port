# Установка и сборка: пошаговая инструкция

Документ описывает два пути. Выберите свой.

| Путь | Для кого | Что получите | Сложность |
| --- | --- | --- | --- |
| **А. Играть** | есть готовая папка сборки `homestead-horizon-stageNN` от автора | запуск игры двойным щелчком | лёгкая |
| **Б. Собрать из исходников** | разработчики | клиент Horizon с нашими модулями, `.hmod` из ваших JAR | сложная, 1-2 часа и ~30 ГБ |

> **Важно.** Готовые сборки в этом репозитории **не лежат**: в них чужие моды, текстуры и клиент, выкладывать их нельзя (см. `NOTICE.md`). Путь А работает, только если вам передали папку сборки лично.
> Путь Б проверен у автора на его рабочей папке. На чистой машине по этой инструкции целиком он **не прогонялся**, поэтому места, где вы можете споткнуться, помечены ⚠.

---

## Что понадобится в любом случае

- Windows 10/11, 64-бит.
- [PowerShell 7](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows) (команда `pwsh`). Встроенный Windows PowerShell 5 не подойдёт для скриптов сборки.
- Видеокарта с поддержкой Vulkan или DirectX 12 (клиент рисует через wgpu).
- Установленная сборка **Homestead - A Cozy Survival Experience** (через CurseForge) или хотя бы нужные вам моды: из их JAR локально берутся ресурсы и данные. Мы их не распространяем.
- Подготовленные ресурсы Horizon для Minecraft 26.3: папка `horizon-client\26.3` внутри данных Horizon Launcher (`...\horizon-launcher\versions\<сборка>\.local\horizon-client\26.3`). В ней должен лежать файл `facts.json`. Откройте Horizon Launcher один раз и запустите любую версию 26.3, папка появится.

## Путь А. Играть из готовой папки сборки

**Быстро (рекомендуется).** Скачайте нашу сборку и установите основную сборку Homestead из CurseForge. Затем запустите `Install-Homestead.cmd` (он лежит в корне репозитория) и ответьте на три шага:

1. **Наша сборка:** путь к папке или `.zip`. Из архива скрипт сам распакует в пустую папку, которую вы укажете (потом её нельзя переименовывать и переносить).
2. **Homestead:** путь к папке экземпляра CurseForge. Скрипт сам ищет его в стандартных местах, достаточно нажать Enter.
3. **Ресурсы Horizon 26.3:** скрипт находит их сам через папку Horizon Launcher. Если нет, откройте лаунчер, запустите любую версию 26.3 и укажите папку `horizon-client\26.3` (в ней `facts.json`).

Скрипт проверяет файл Create в Homestead, записывает `local-settings.json` и предлагает запустить игру. Без вопросов: `Install-Homestead.ps1 -OurBuild <путь> -Homestead <путь> -Launch`. Только проверка без записи: ключ `-CheckOnly`.


Готовые сборки больше **не содержат `local-settings.json`**: в нём лежали бы пути вашего компьютера. Файл создаёт `Install-Homestead.cmd` (или вы копируете `local-settings.example.json` в `local-settings.json` и заполняете сами).

**Как сменить ник.** По умолчанию в обзорном мире игрок называется `HomesteadTest`. Ник можно задать при установке (вопрос «Ник»), ключом `Install-Homestead.ps1 -PlayerName <ник>`, полем `playerName` в `local-settings.json` или ключом `Start-Homestead.ps1 -Name <ник>`. Допустимо 3-16 символов: латинские буквы, цифры, `_`. Инвентарь и прогресс в мире привязаны к нику: после смены ника в старом мире вы будете другим игроком.

**Вручную.**

1. Распакуйте папку сборки, например в `D:\Games\homestead-horizon-stage19`. Не переименовывайте и не переносите её потом: игра строит кэш с привязкой к папке.
2. Скопируйте `local-settings.example.json` в `local-settings.json` в этой же папке и впишите два пути (двойные обратные слэши обязательны): `resources` (папка `horizon-client\26.3` с `facts.json`) и `sourceInstance` (папка вашего Homestead).
3. Запустите `Play-Create.cmd` двойным щелчком. Откроется обзорный мир в творческом режиме.
4. **Первый запуск долгий: 3-5 минут.** Игра на чёрном экране с логотипом строит кэш содержимого модов (около 120 тысяч файлов). Это не зависание. Не закрывайте окно и не запускайте вторую копию: прерванная сборка кэша начинается заново. Дальше запуск занимает секунды.
5. В творческом инвентаре есть вкладки Create, Farmer's Delight и остальных модов.

**Если не запускается:**
- `The native client artifact is missing` значит, рядом с `Start-Homestead.ps1` нет `client\horizon-client.exe`: распаковка неполная.
- `Pass -Resources ...` значит, путь в `local-settings.json` неверный или без `facts.json`.
- `already running (PID ...)` значит, игра из этой папки уже запущена. Дождитесь её.
- Вручную из PowerShell 7: `pwsh .\Start-Homestead.ps1 -Review` (обзорный мир) или `-World ИмяМира -Creative`.

## Путь Б. Собрать из исходников

Скрипты рассчитаны на фиксированную раскладку папок внутри корня репозитория (`work\...`). Ниже она задаётся явно.

### Б.1. Инструменты (одна установка)

Положите в корень репозитория, в папку `work\`:

| Папка | Что внутри | Версия |
| --- | --- | --- |
| `work\toolchain\` | Rust (`bin\cargo.exe`, `rustc.exe`, `rustfmt.exe`) | **1.99.1** (дата 2026-10-15, см. `compatibility.json`) |
| `work\llvm-mingw\llvm-mingw-20261104-msvcrt-x86_64\` | компилятор clang для Windows и встроенный Python в `python\bin\python.exe` | **20261104, msvcrt, x86_64** |
| `work\mingit\` | портативный Git (`cmd\git.exe`) | любой свежий |
| `work\cargo-home\` | кэш Cargo, создастся сам | пустая папка |

⚠ Точные дистрибутивы автор получал вручную. Если версии отличаются, сборка может не пройти.

Файл `work\rust-env.ps1` лежит в репозитории: он добавляет эти папки в PATH и задаёт `CARGO_HOME`, `RUSTC`, `CC`, `CXX`, `AR` и линкер clang. Править его не нужно.

### Б.2. Исходники двух зависимостей

Нужны две точные ревизии (оба проекта под MIT):

1. Клиент Horizon: ревизия `4e5296d1800b3f89f2ae48dfd99d431801df4d46` из `github.com/horizon-rust/horizon`. Распакуйте в `work\homestead-horizon\engine\horizon-4e5296d1800b3f89f2ae48dfd99d431801df4d46\`.
2. Инструмент миксинов: ревизия `e8cd0aa38cffef49cb2e088ef716baa107148c02` из `github.com/horizon-rust/horizon-mixins`. Распакуйте в `work\homestead-horizon\mixins-tool\horizon-mixins-e8cd0aa38cffef49cb2e088ef716baa107148c02\` и соберите: `cargo build` там даст `target\debug\horizon-mixins.exe`.

Затем запустите скрипт путей. Он сам создаёт три файла `create-source-path.txt`, `engine-source-path.txt`, `mixins-source-path.txt` в `work\homestead-horizon\` с полными путями вашей машины и проверяет, что на месте инструменты и исходники:

```powershell
pwsh work\homestead-horizon\Setup-Paths.ps1
```

Каждая строка `НЕТ` в его выводе говорит, чего не хватает; `OK` значит, что всё найдено. Запускайте его после каждого шага установки, пока не останутся одни `OK`. Эти три файла в `.gitignore`, потому что в них абсолютные пути.

### Б.3. Настройки

В корне репозитория:

```powershell
Copy-Item local-settings.example.json local-settings.json
```

Откройте `local-settings.json` и впишите:
- `resources` путь к `...\horizon-client\26.3` (с `facts.json`);
- `sourceInstance` путь к папке вашей установки Homestead в CurseForge.

Файл в `.gitignore` и не публикуется.

### Б.4. Моды из ваших JAR

```powershell
pwsh work\homestead-horizon\stage4\Build-LocalMods.ps1
```

Скрипт собирает `.hmod` для Farmer's Delight из вашего JAR в локальную папку. Остальные «данные»-моды (`Build-DataMods.ps1`) требуют каталогов `work\homestead-horizon\pack\mods\<мод>\carry`, которые создаёт инструмент `horizon-port-pack carry` из ваших JAR. ⚠ Этот шаг пока ручной и в репозитории не описан подробнее.

Оригинальные текстуры Create: положите **свой** JAR Create 6.0.10 в `horizon-mods\create-resources\` (см. `docs\assets.md` внутри `create-source`). Без него используются нарисованные заготовки.

### Б.5. Сборка клиента

```powershell
pwsh work\homestead-horizon\stage4\build.ps1
```

Это 10-15 минут при тёплом кэше, дольше в первый раз. Скрипт сам:
1. генерирует контент (`tools\content.py`),
2. накладывает наши миксины на клиент (`horizon-mixins apply`),
3. применяет патчи движка из `stage4\engine-patches`,
4. собирает клиент профилем `fast`.

Ошибки компиляции ищите в `stage4\game-build.log` по строкам, начинающимся с `error`.

После сборки скопируйте клиент в кандидат:

```powershell
pwsh work\homestead-horizon\stage4\Prepare-Candidate.ps1
```

### Б.6. Проверка

```powershell
pwsh work\homestead-horizon\stage4\Run-Acceptance.ps1 -ReloadOnly   # короткая проверка запуска
pwsh work\homestead-horizon\stage4\regress.ps1                       # полная регрессия, около часа
```

Запускайте **одну игру за раз**: две копии одновременно портят генерацию контента. Тесты открывают окно игры.

## Частые вопросы

**Почему так долго грузится первый раз?** Клиент строит кэш содержимого модов (около 1 ГБ). Дальше быстро. Если закрыть игру посреди сборки кэша, он начнётся заново.

**Можно ли переименовать папку сборки?** Нет, кэш привязан к пути. После переноса первый запуск снова долгий.

**Где мои сохранения?** В папке сборки: `private\` (в ней экземпляр игры и миры). Она не публикуется и не входит в git.

**Можно ли выложить мою сборку?** Нет: в ней чужие моды, текстуры и клиент. Публиковать можно только исходный код из этого репозитория.
