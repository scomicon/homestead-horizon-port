# Homestead Horizon

Экспериментальный перенос сборки Homestead на Rust для нативного клиента [Horizon](https://playhorizon.dev): мод Create, Farmer's Delight и ряд мелких модов логики. Репозиторий содержит **только исходный код, скрипты, тесты приёмки и документы**. Чужих модов, текстур, моделей, звуков, клиента и готовых сборок здесь нет, их нужно получить самому (см. «Сборка из исходников»).

> Проект неофициальный. Он не связан с Mojang, Microsoft, авторами Create, Farmer's Delight и остальных модов. Minecraft — торговая марка Mojang/Microsoft.

## Быстрый старт

Если у вас есть готовая папка (или `.zip`) нашей сборки, которую вам передал автор, и установлена сборка **Homestead - A Cozy Survival Experience** из CurseForge:

0. **Сначала распакуйте архив целиком** (правая кнопка → «Извлечь все...»). Запуск прямо из открытого в проводнике `.zip` не работает: Windows вытаскивает из него только один файл.
1. Запустите **[Install-Homestead.cmd](Install-Homestead.cmd)** (двойной щелчок; лежит в корне этого репозитория).
2. Укажите путь к нашей сборке и к Homestead. Скрипт сам находит Homestead и ресурсы Horizon, обычно достаточно нажимать Enter.
3. Согласитесь на запуск. **Первая загрузка занимает 3-5 минут**: игра строит кэш модов. Не закрывайте окно и не запускайте вторую копию.

> **Скачанный с GitHub архив (`Code → Download ZIP`) это исходный код, а не игра.** Его папку в установщик указывать не нужно: он сообщит, что игры в ней нет. Готовую сборку (папку `homestead-horizon-stageNN` или `.zip`) передаёт автор лично.

Готовых сборок в этом репозитории нет: в них чужие моды, текстуры и клиент, публиковать их нельзя. Подробная инструкция, ручная установка и сборка из исходников: **[INSTALL.md](INSTALL.md)**.

## Состояние

Состояние кода: **stage22** (последний собранный релизный пакет — **stage20**, 38 наборов приёмки). На пересобранном бинарнике stage22 пройдено 40 из 41 набора приёмки; набор `-ClientS` (звук) не прошёл только в фазе `Playback` из-за отсутствия аудиовыхода WASAPI на сборочной машине. На живом клиенте проверено только в творческом режиме. Выживание, внешний вид и многие рецепты не проверены.

| Create: жидкости | мультиблочный бак, сеть труб, насосы, котёл на баке |

| Create: декор | около 350 декоративных блоков на ванильных шаблонах |
| Farmer's Delight | еда, разделочная доска, печь, сковорода, котёл с экраном, посевы, пиры |

| Клиент: подсказки, HUD и звук | переписаны по публичным описаниям: описания и инфо о зачарованиях, рамка редкости, Detail Armor Bar, Better Mount HUD, Traveler's Titles, Welcome Screen, звуковые модули Extreme Sound Muffler, Presence Footsteps, AmbientSounds |

**Не перенесено, отключено или не подтверждено:**

- **Stack Refill и CraftingPad отключены.** Их хуки выполняются на серверном потоке, где у игры нет локального игрока, экрана и инвентаря, поэтому в одиночной игре они ничего не делают. Код оставлен в репозитории, в сборку не входит (`docs/logic-c.md`).
- **Trade Cycling, Bridging Mod, SimpleHats** требуют хуков движка, которых нет. `Comforts` и `Grind Enchantments` перенесены с помощью локальных патчей `stage4/engine-patches/20..22-*.ps1`, но с упрощениями (у точила нет кнопок и проверки нехватки уровней, спальные мешки используют шаблон кровати без оригинальных моделей и дневного сна).
- **Эффект Comfort и Nourishment** идут через тот же серверный хук. В одиночной игре Comfort, скорее всего, не лечит, это не проверено.
- **Официальные моды Horizon (Zoom, Minimap, Recipes)** недоступны в сборке: они вплавляются при сборке клиента, а условия их распространения не подтверждены.
- **Не проверено в игре:** перехват звука (`native_sound_play`, `hook_seen=0` из-за отсутствия аудиовыхода WASAPI на тестовой машине), Better Mount HUD (езда на скакуне не проверена сокетом), работа Comforts (спальный мешок и точка возрождения) и забор результата в Grind Enchantments (сокет не кликает по меню), невидимость рамок, смерть игрока и SpawnFilter, внешний вид баннера, приветственного экрана, подсказок и плюшей.

**Не сделано:** поезда Create, копикэты, предпросмотр схем, большинство экранов (GUI) Create, сущности и рендер модов, зависящих от слоя сущностей в Horizon mod API. Полный список и известные долги: `work/homestead-horizon/stage4/research/roadmap.md` и `docs/` внутри `create-source`.

## Сборка из исходников

Для разработчиков. Полная пошаговая инструкция с версиями и ссылками: [INSTALL.md](INSTALL.md), путь Б. Коротко, чего нет в репозитории и нужно получить самому:

1. Исходники клиента Horizon и `horizon-mixins` (оба MIT) по двум точным ревизиям, а также Rust 1.99.1 и llvm-mingw в папке `work/`.
2. **Свои копии модов.** Установите сборку Homestead (CurseForge) или нужные моды сами. Скрипты разбирают ваши JAR локально.
3. Оригинальные ресурсы Create: положите JAR Create, который вы скачали сами, в `horizon-mods/create-resources/` (см. `docs/assets.md`). Без него игра использует встроенные нарисованные заготовки.

Дальше:

```powershell
pwsh work/homestead-horizon/Setup-Paths.ps1                  # создать файлы путей и проверить инструменты (повторяйте, пока всё OK)
Copy-Item local-settings.example.json local-settings.json    # впишите свои пути
pwsh work/homestead-horizon/stage4/Build-LocalMods.ps1       # собрать .hmod из ваших JAR в локальную папку
pwsh work/homestead-horizon/stage4/build.ps1                 # собрать клиент (~10-15 минут)
pwsh work/homestead-horizon/stage4/Run-Acceptance.ps1 -ReloadOnly
```

`local-settings.json`, `local/`, `private/`, `outputs/` и любые `.hmod`, `.jar`, `.exe` игнорируются git и **не должны публиковаться**: в них чужие ресурсы.

## Ограничения

- Часть рецептов, форм и звуков оценена, а не сверена с оригиналом.
- Ядра Create писались по пересказу исходников, не по локальной копии, и не сверены построчно.
- Запуск двух копий клиента одновременно портит генерацию контента: запускайте одну.
- Первая загрузка с большим числом модов занимает 3-5 минут: клиент строит кэш контента (около 1 ГБ). Не закрывайте окно, иначе сборка кэша начнётся заново.
- Путь «Сборка из исходников» целиком на чистой машине не проверялся: места, где можно споткнуться, помечены в INSTALL.md знаком ⚠.
