# Farmer's Delight, срез stage23: корзины, шкафы, циновки, канатные заборы, колонии грибов

Farmer's Delight 2.4.1 (Refabricated, MIT). Срез написан без сборки и без запуска игры: Java оригинала для него
не читалась, поведение восстановлено по памяти о версии 1.20 (vectorwing). Всё, что отмечено «оценка», нужно сверить с оригиналом.
Содержимое: `fd/stage23.py` (объявления блоков поверх перенесённых данных), проверка содержимого `tools/fd_stage23_content.py`.
Поведение: `mixins/homestead/storage.rs` (модуль `homestead_storage`) и `colony.rs` (модуль `homestead_colony`).
Общие файлы этим срезом не тронуты: правки для интегратора лежат в `mixins/homestead/fragments/fd-stage23.md` и `.toml`.
Приёмка: `ST/acceptance/Test-Homestead-FdStage23.ps1` (префикс `stage23-fd-`, 17 сценариев).

## Сделано

| Что | Как |
| --- | --- |
| Корзина `basket` | Шаблон `minecraft:barrel`: его «использование» открывает меню мода. 27 слотов в блок-сущности, стандартное меню `minecraft:generic_9x3`, доступ воронок и Create со всех граней. Состояние `facing` по шести сторонам, при установке равно нажатой грани. Форма: открытый ящик модели (пол 2 пикселя и четыре стенки), повёрнутый под каждую сторону (в `fd/stage23.py`, проверено юнит-проверкой геометрии). Затягивание: каждые 8 тиков предметы-сущности в клетке перед отверстием попадают в корзину (как воронка сверху). |

Установка: горизонтальное направление, противоположное взгляду (`CabinetBlock.getStateForPlacement`), никогда вверх или вниз. В перенесённые blockstate добавлены варианты `facing=up|down` (модель севера), чтобы блок, поставленный поршнем или командой, не терял модель. |
| Холщовая циновка `canvas_rug` | Шаблон `white_carpet` вместо камня: тонкая пластина высотой 1 пиксель, звук шерсти. Перенесённая модель с декоративными выступами используется как есть. |
| Половина татами `half_tatami_mat` | Перенесённая оболочка (тыква, `facing`) получила форму высотой 2 пикселя, соответствующую модели. |
| Верёвка `rope` | Её в переносе не было. Лазание: перенесённая метка `minecraft:climbable` уже содержит верёвку. |

| Лут и рецепты | Перенесённые: ломание колонии даёт 2-5 грибов по `age`, зрелая колония с ножницами даёт саму колонию; рецепты корзины, шкафов, циновки. Корзина и шкафы в перенесённом луте копируют имя блок-сущности. |

## Отличается от оригинала

- **Корзина:** нет управления красным камнем (в оригинале её можно отключить сигналом), нет отдельной анимации и звука открытия, нет плавучести (`waterlogged`).
  Затягивание: оригинальную область и период (оценка 8 тиков) не сверяли; затягивается клетка перед отверстием целиком, а не ограниченный воронкой объём. Предмет-сущность затягивается и из воздуха, не только падающий.
- **Шкафы:** свойство `open` ведёт шаблон бочки; переключение модели «дверца приоткрыта» при открытом меню и звуки `cabinet.open/close` не проверены и не реализованы отдельно. Сторонние шкафы метки `farmersdelight:cabinets` не обрабатываются.
- **Верёвка:** не реализованы лазание томатной лозы по верёвке (`ropelogged`, `crop_with_rope`, рост лозы вверх; ждёт доработки `crops.rs`), привязка к колоколу (`tied_to_bell` всегда `false`), сматывание верёвки при `Shift + пустая рука` (`enableRopeReeling`), правило установки только на опору или верёвку. Соединения идут по шаблону `chorus_plant` с меткой `ropes`, а не по правилам `RopeBlock`. Рецепта верёвки нет (в переносе его не было, а по памяти оригинала не уверен, что он есть): верёвка берётся в творческом режиме из вкладки.
- **Колонии:** оценка шансов роста (1 к 4 на случайный тик почвы); нет роста от костной муки; нет прямого сбора ножницами правым кликом (только лут при ломании); форма как у шаблона-гриба, а не по стадиям; расползание колоний и мировая генерация (на грибных полях) не сделаны (дикие культуры и генерацию владелец исключил).
- **Циновки и татами:** `tatami` (поле `facing` по шести сторонам и `paired`) и `full_tatami_mat` (две части, как кровать) **не объявлены**: для них у движка нет шаблона с нужными свойствами; нужен либо шаблон блока с 6-сторонним `facing` без побочного поведения, либо разрешение на `facing`-блок без шаблона (запрос к Horizon). `half_tatami_mat` оставлен как оболочка с правильной формой. Холщовая циновка (`canvas_rug`) не имеет `waterlogged`-варианта и огнеупорности.
- **Топливо** (`minecraft:cooking_fuel` для холста, шкафов, корзин, соломы) в этом срезе не добавлено: форма компонента не сверена.
- **Холщовые таблички** уже перенесены оболочками (шаблоны табличек), не менялись.

## Не проверено

Ничего из этого не собиралось и не запускалось (в этой волне сборки нет по правилам проекта: одна копия игры за раз).

1. **Компиляция Rust.** Проверен только разбор синтаксиса `rustfmt`. Предположения, которые может опровергнуть компилятор:
   `ItemStack::same_item_same_components`, `game.native_item_entities(&dim, min, max)` и `native_set_item_entity` берутся как в `belt_funnel.rs` (в моём коде нужен `dim: String` из `game.dim.id().to_owned()`),
   `ModContainer` с заполненными `faces`/`inputs`/`outputs` (у котла эти списки пустые, значит заполненные списки в игре не проверялись),
   `entity.items` как `Vec<Option<ItemStack>>` (как в `cooking_pot.rs`), `native_state_block(state)` возвращает `Option<&str>` (как в `cooking_pot.rs`).
2. **Содержимое.** Загрузка `.hmod` с шаблонами `barrel` (шкафы и корзина), `chorus_plant` с `connects_to` и `thickness`, `white_carpet`, `brown_mushroom`/`red_mushroom` с `random_ticks: false`. Если загрузчик отвергает объявление, `-ReloadOnly` и `-FarmersDelight` покажут это сразу. Проверка `tools/fd_stage23_content.py` подтверждает только согласованность файлов (blockstate, модели, лут, язык), не загрузку движком.
3. **Шаблон бочки без блок-сущности ванильной бочки.** Открывается ли меню 9x3 и пишется ли `open`, зависит от того, как движок связывает шаблон `barrel` с `ModContainer` (у котла так работает, но у него меню своего типа, у корзины и шкафов ванильное `generic_9x3`).
4. **Выживание.** Всё проверялось бы в творческом режиме через сокет; ломание корзины с содержимым, лут с `copy_name`, ножницы на зрелой колонии.
5. **Колония и ванильный гриб.** Предположение: `random_ticks: false` отключает расползание грибов шаблона. Если сценарий «колония растёт без простых грибов» красный, нужно либо сменить шаблон на растение без тика (`fern`/`short_grass` плюс свойство `age` и метка выживания), либо добавить в хук обработку.
6. **Выживание колонии на богатой почве и шанс роста** (1 к 4) и **частота затягивания** корзины (8 тиков).
7. **Лазание по верёвке** руками игрока через сокет не проверить (приёмка проверяет только соединение вверх).
8. **Внешний вид:** форма корзины при поворотах, шкаф с открытой дверцей, циновка с выступами, верёвка с боковыми частями, колонии по стадиям.

## Нужные хуки и запросы к Horizon

- Хук правой кнопки с ножницами для зрелой колонии не нужен (хватает `right_click_block`), но тогда надо переписывать лут/ножницы: отложено.
- Хук на изменение блока сверху для лозы, лезущей по верёвке (`ropelogged`): нужен `neighbor_changed` на клиентской стороне мира или расширение `crops.rs`; отложено до следующего среза FD.
