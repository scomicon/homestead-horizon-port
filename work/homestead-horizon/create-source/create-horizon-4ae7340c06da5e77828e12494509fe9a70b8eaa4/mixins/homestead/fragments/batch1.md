needed.** The client binary of the last accepted stage is enough; the batch ships as content mods
(`.hmod`) plus one data pack.

## 4. `ST/package/Start-Homestead.ps1` (the launcher shipped in the package)

The launcher copies only `datapacks/homestead-create` into `new-world-datapacks`. Replace the block

```powershell
$pack = Join-Path $root 'datapacks/homestead-create'
if (Test-Path -LiteralPath (Join-Path $pack 'pack.mcmeta')) {
    $templates = Join-Path $game 'new-world-datapacks'
    New-Item -ItemType Directory -Force -Path $templates | Out-Null
    Copy-Item -LiteralPath $pack -Destination $templates -Recurse -Force
}
```

with a loop over every data pack folder (so `homestead-sparse` is installed too; ASCII only, the file is read by
Windows PowerShell 5):

```powershell
$templates = Join-Path $game 'new-world-datapacks'
foreach ($pack in Get-ChildItem -LiteralPath (Join-Path $root 'datapacks') -Directory -ErrorAction SilentlyContinue) {
    if (Test-Path -LiteralPath (Join-Path $pack.FullName 'pack.mcmeta')) {
        New-Item -ItemType Directory -Force -Path $templates | Out-Null
        Copy-Item -LiteralPath $pack.FullName -Destination $templates -Recurse -Force
    }
}
```

Worlds that already exist keep what they have; SparseStructures only affects worlds created afterwards.

## 7. Risks for the first run

- `horizon-port-pack carry` was never run on these jars here. Its choice of what to load (blocks the
  loader does not know, recipe types, GeckoLib models, custom loot conditions) decides the final counts; the
  acceptance script samples and reports instead of assuming.
- Mod ids with `-` (Go Fish may carry `go-fish`): `Build-Batch1.ps1` throws with an explanation; fix by renaming
  in the carry step, otherwise the mod would stay disabled.
- `recipe give`, `loot give` and `execute if block ... #tag` are vanilla-style commands; if the client does not
  implement them the script records a note, not a pass.
- SparseStructures needs `data/minecraft/worldgen/structure_set` in the prepared resources (present in the
  resources inspected here) and applies to new worlds only.
